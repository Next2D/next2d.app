ABOUT THE GAME

どんなゲーム?

画面には数字を持ったスライムが4体並んでいます。スライムを2体タップすると、 「a+b」「a−b」「a×b」など6つの計算候補が現れるので、好きな式を選びましょう。 選んだ2体は式の答えを持つ1体に合体します。

これを繰り返して、最後に残った1体が「10」ならクリア。10以外の数字で終わるとゲームオーバーです。

出題は必ず10が作れる組み合わせだけを検証して生成しています。理不尽な詰みはありません。

この4体から、10が作れる組み合わせを見つけよう

3 STEPS

あそびかた

操作はとってもシンプル。スライムを選んで、式を選ぶだけです。

1

スライムを2体えらぶ

計算したい2体をタップ(コントローラーでも選択可)。

2

けいさんをえらぶ

a+b / a−b / b−a / a×b / a÷b / b÷a から式をえらぶ。

3

くりかえして、さいごの1体を10に!

最後の1体が10ならクリア。10以外だとゲームオーバー。

FEATURES

とくちょう

理不尽ゼロの出題

すべての問題は「必ず10が作れる」ことを検証してから出題。運ゲーではありません。

難しさは自分でえらべる

掛け算・割り算・マイナスの数・分数をON/OFFで調整。初期状態は全OFFなので、小さな子どもから遊べます。

× 掛け算 OFF
÷ 割り算 OFF
− マイナスの数 OFF
½ 分数 OFF

難しい設定ほど高スコア

マイナスの数+5点、分数+10点、掛け算ON+5点など、難易度に応じたボーナス点で高得点を狙えます。

タップでもコントローラーでも

スマホのタップ操作はもちろん、ゲームパッド(コントローラー)にも完全対応。
