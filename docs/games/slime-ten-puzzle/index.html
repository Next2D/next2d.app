あそびかた

操作はとってもシンプル。スライムを選んで、式を選ぶだけです。

1

スライムを2体えらぶ

計算したい2体をタップ(コントローラーでも選択可)。

2

けいさんをえらぶ

a+b / a−b / b−a / a×b / a÷b / b÷a から式をえらぶ。

3

くりかえして、さいごの1体を10に!

最後の1体が10ならクリア。10以外だとゲームオーバー。

おすすめポイント

計算に強くなる!

遊ぶだけで四則演算の暗算トレーニング。「どの2つで10に近づける?」を考えるうちに、数の組み合わせ感覚が自然と身につきます。

子どもから大人まで

最初はたし算・ひき算だけ。設定で掛け算・割り算・マイナス・分数まで広げられるので、学びの段階に合わせて親子で一緒に楽しめます。

× 掛け算 OFF
÷ 割り算 OFF
− マイナスの数 OFF
½ 分数 OFF

スキマ時間の脳トレ習慣に

1問サクッと解ける気持ちよさ。かわいいスライムに癒やされながら、1分タイムアタックで毎日の脳トレが続きます。

1分5分10分

ゲームモード

ノーマル

時間無制限。クリアするたびに次の問題が出るエンドレスモード。

タイムアタック

1分・5分・10分から時間を選択。モードごとにハイスコアを記録できます。

チュートリアル

手のカーソルが次に押すスライムとおすすめの計算をナビゲートしてくれます。
